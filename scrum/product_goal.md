# Product Goal

## Product
**CalendarStream Dashboard**

## Product vision
A Flutter dashboard that helps the Product Owner and team inspect requirements, manage sprint work, and follow issues, usage, and agent progress.

## Current Product Goal
**Deliver the CalendarStream dashboard described by the dashboard requirements.**

### Conditions for achieving the goal
1. The dashboard runs as a web app and a desktop app using Dart and Flutter.
2. The dashboard presents and manages the requirements, sprint blocks, issues, usage, and agent progress defined by DSH-01 through DSH-16.
3. The apps follow the linked shared requirements for UI, theme, defaults, and messages.
4. The web app uses the local server and the desktop app uses the same data interface.
